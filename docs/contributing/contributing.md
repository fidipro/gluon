Bug reports are welcome. Pull requests are welcome too: Gluon is licensed under the Apache License 2.0, and code you contribute is licensed the same way.

These files, in the repository root, are the source of truth:

- [CONTRIBUTING.md](../../CONTRIBUTING.md) covers setting up from source, the test suite and the rules every change must keep.
- [CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md) is what everyone taking part follows.
- [SUPPORT.md](../../SUPPORT.md) says where to ask questions.
- [AGENTS.md](../../AGENTS.md) holds the project notes for coding agents, with a file per area of the code.
- [CHANGELOG.md](../../CHANGELOG.md) lists the changes.

To report a vulnerability, do it privately: see [SECURITY.md](../../SECURITY.md).
